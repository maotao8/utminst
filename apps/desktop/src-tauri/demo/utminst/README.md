## 如何安装

### 下载安装包

点击 **下载链接** 并选择需要下载的文件；

[GitHub 下载链接](https://github.com/maotao8/utminst/releases/latest)

[Gitee 下载链接](https://gitee.com/maotao8/utminst/releases/latest)

将目标文件保存到本地下载目录；

### 安装软件

打开下载目录文件夹，找到下载好的 utminst 安装文件；

点击 utminst 安装文件，运行安装。

## 怎样使用

### 方法一：安装向导程序引导安装与配置

选择 utminst 图标，运行软件并根据提示完成系统的安装与配置。


### 方法二：手动安装系统并配置

如果未安装 utminst 应用，也可以参考以下步骤完成系统的安装与配置。

1. 下载并安装 F-Droid 客户端

[GitLab 主站点](https://gitlab.com/fdroid/fdroidclient)

[南京大学镜像站点](https://mirror.nju.edu.cn/fdroid/repo/)

[备份镜像最新版本 - 1.23.2](https://www.koudaipc.com/demo/mirrors/fdroid/repo/org.fdroid.fdroid_1023052.apk)

[备份镜像 1.23.2 PGP 签名](https://www.koudaipc.com/demo/mirrors/fdroid/repo/org.fdroid.fdroid_1023052.apk.asc)

2. 安装 Termux 0.118.3 (1002)

在 F-Droid 中搜索 Termux 选择版本 0.118.3 (1002) 并安装

或者直接下载备份镜像安装

[Termux 备份镜像 - 0.118.3 (1002)](https://www.koudaipc.com/demo/mirrors/fdroid/repo/com.termux_1002.apk)

[Termux 备份镜像 PGP 签名](https://www.koudaipc.com/demo/mirrors/fdroid/repo/com.termux_1002.apk.asc)

3. 在 Termux 中下载并运行一键安装脚本


根据主机用途可选择 **仿真器** 栏获取相关的推荐软件进行安装

1. 点击页面头部的 **仿真器** [html](./qemu/index.html) [md](./qemu/README.md) ；

2. 根据主机用途选择对应的仿真器；

3. 根据仿真器列出的软件选择安装。

### 下载虚拟系统

根据主机用途可选择 **虚拟系统** 栏获取相关的推荐系统进行安装

1. 点击页面头部的 **虚拟系统** [html](./vmos/index.html) [md](./vmos/README.md) ；

2. 根据主机用途选择对应的系统方案；

3. 根据分类版面列出的系统方案选择安装。
